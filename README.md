# ecommerce-project-c41-onl

# Маркетплейс
Веб-приложение на Java (Spring Web MVC + Jakarta EE) с каталогом товаров, авторизацией, ролевой моделью и отзывами.

## Технологический стек
Язык и среда: Java 21 (JDK 21).
Сборка: Apache Maven.
Фреймворк: Spring Framework, Spring Web MVC.
Валидация: Bean Validation (Hibernate Validator).
Доступ к данным: JDBC (нативный уровень), Flyway (миграции БД).
Представление:  Thymeleaf, Bootstrap CSS (верстка).
База данных: PostgreSQL.
Спецификации: Jakarta EE.

## Функциональные возможности

### Управление пользователями и ролями
- **Регистрация и вход**: формы регистрации и аутентификации с валидацией данных.
- **Сессии**: управление состоянием пользователя (авторизация, выход).
- **Удаление аккаунта**: безопасная функция удаления учетной записи.
- **Ролевая модель**: разграничение прав доступа (роли SELLER и BUYER).
- **Профиль продавца**: расширенная секция «О продавце» (сведения об ИП/юрлице, контакты) — доступна только пользователям с ролью продавца.
### Каталог товаров
- **Карточки товаров**: создание, просмотр и отображение детальной информации о товаре.
- **Категории**: разделение товаров по разделам (компьютерная техника, смартфоны, бытовая техника и т.д.).
- **Поиск**: поиск товаров по названию.
- **Фильтрация**: фильтрация каталога по выбранным разделам. Каталог отображается на главной странице.
### Взаимодействие с товарами
- **Комментарии**: пользователи могут оставлять текстовые комментарии к товарам.
- **Избранное**: функционал добавления товаров в список «Избранное» для последующего просмотра.
- **Рейтинги**: оценка товаров по шкале от 1 до 5 звезд.
